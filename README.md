## About

I am an **AI/ML-focused Computer Science graduate currently pursuing an M.S. in Data Science & Machine Learning at the National University of Singapore**, specializing in **computer vision and medical image segmentation**.

My work spans the full machine-learning lifecycle — from data processing and experimentation to model development, benchmarking, optimization and application deployment. I am particularly interested in engineering problems where **machine learning research, computer vision and software development intersect**.

I have built systems using **PyTorch, TensorFlow, OpenCV and Hugging Face**, with experience across segmentation, pose and object detection, Transformers, LoRA/PEFT, RAG and multimodal AI. I approach engineering through **methodical experimentation, measurable benchmarking and following technical problems through to working solutions**.

My research includes **first-author work published at ICCIS 2025 in the Springer Book Series** on prostate segmentation and a **published patent for a multimodal sign language translation system**.

## Featured Projects

<details>
<summary><strong>01 · LoRA Fine-tuning Framework for Medical Image Segmentation</strong></summary>

<br>

A parameter-efficient medical image segmentation framework implementing **Low-Rank Adaptation from scratch for MedSAM (ViT-B)**, designed to improve segmentation performance while dramatically reducing trainable parameters and training overhead.

| Dimension | Details |
|:---|:---|
| **Stack** | Python · PyTorch · MedSAM · ViT-B · LoRA |
| **Domain** | Medical Image Segmentation |
| **Performance** | **95.7% Dice · 91.9% IoU** |
| **Efficiency** | **82% fewer trainable parameters** |
| **Optimization** | Per-epoch training reduced from **60 min → 3 min** using embedding caching |
| **Repository** | [MedSAM_LoRA](https://github.com/AmitejSingh1/MedSAM_LoRA) |

### Engineering Highlights

- Implemented a **LoRA trainer from scratch** and applied it to MedSAM's ViT-B architecture.
- Fine-tuned the model specifically for prostate segmentation.
- Achieved **95.7% Dice and 91.9% IoU**.
- Surpassed the previous VGG-UNet baseline while using **82% fewer trainable parameters**.
- Optimized the training pipeline through image embedding caching.
- Reduced per-epoch training time from approximately **60 minutes to 3 minutes**.
- Maintained high segmentation performance while substantially reducing training overhead.

</details>

- Implemented post-processing boundary correction for more precise segmentation outputs.
